# AI에게 A부터 Z까지 맡기기

저장소 주소: https://github.com/ChungmaruQ/stable-captions

Azure 계정이나 서비스가 전혀 없어도 시작할 수 있습니다. Claude/Opus, GPT Astra/Sol 등 파일·터미널 또는 브라우저 작업이 가능한 에이전트에 아래 내용을 붙여 넣으세요. 특정 AI 모델의 이름보다 저장소 지침을 읽고 실제 작업할 수 있는 도구가 중요합니다.

## 복사해서 요청하기

> https://github.com/ChungmaruQ/stable-captions 를 클론하고 AGENTS.md, docs/AZURE_AGENT_RUNBOOK.md, docs/AZURE_SETUP.md, docs/BUILD_AND_TEST.md를 읽어 주세요. 나는 초보자이며 Azure 계정·구독·서비스가 하나도 준비되어 있지 않을 수 있습니다. 환경 확인부터 계정/구독 준비 안내, 사용 가능한 지역·모델·쿼터와 비용 확인, 필요한 Azure 리소스 생성, 개인 설정 저장, 두 Windows EXE 빌드, 실제 자막 시험까지 A부터 Z까지 맡아 주세요. 설명이나 문서 링크만 주고 끝내지 말고, 가능한 작업은 CLI/API/내가 허용한 브라우저로 직접 수행하세요. 로그인·MFA·결제 동의 등 내가 해야 하는 순간에는 지금 할 행동 한 가지를 알려 주고, 내가 마치면 다음 단계부터 계속하세요. 유료 작업은 실제 리소스/SKU/지역/모델·요금과 짧은 연결 시험 계획을 제시해 내 확인을 받은 뒤 진행하고, 같은 승인 범위는 반복해서 묻지 마세요. 키는 채팅·코드·Git·EXE에 넣지 말고 내 PC의 개인 설정 파일로 연결하세요. Windows 작업은 바탕화면 StableCaptions-Workspace/Project_Public에서 하고 기존 자료를 보존하세요. Windows가 없으면 내 GitHub Fork의 Actions로 빌드하세요. 마지막에는 서비스 생성·인증·마이크 자막·화면 분석의 검증 결과, EXE 위치와 남은 내 행동을 구분해 알려 주세요.

## 에이전트가 따라갈 순서

1. OS·개발 도구·로그인·구독 상태를 직접 조사합니다.
2. 계정이나 구독이 없으면 가입부터 안내하고 사용자 인증 완료 후 이어갑니다.
3. 대상 구독의 지역·모델·쿼터·비용을 확인해 구체적인 생성 및 짧은 시험 계획을 제시합니다.
4. 승인 후 에이전트가 Speech·모델 배포·필요한 경우 Vision을 생성합니다.
5. 발급된 설정을 비공개로 가져와 앱과 연결합니다.
6. 두 Windows 실행파일을 빌드하고 오프라인 검증합니다. 계정 승인을 기다리는 동안 이 단계는 먼저 할 수 있습니다.
7. 승인된 범위에서 사용자의 마이크와 화면으로 실제 작동을 확인하고, 다음 실행과 종료 방법까지 설명합니다.

자세한 실행 명령·오류 대응·완료 기준은 [에이전트 실행 절차](AZURE_AGENT_RUNBOOK.md)에 있습니다. 사용자는 Azure 전문가일 필요가 없으며 비밀번호·인증·결제 동의와 실제 발화 등 본인이 해야 하는 단계에만 참여합니다. 도구/권한 제약이나 구독 승인이 남으면 에이전트는 그 부분을 명시하고 계속할 다음 행동을 안내해야 합니다.
