# 데이터와 비용

- 음성 인식 시작 후 마이크 오디오가 사용자의 Azure Speech로 전송됩니다.
- 맥락 번역을 사용하면 현재 발화와 제한된 이전 발화/표시 문구가 사용자의 Azure 모델로 전달됩니다.
- 화면 분석을 켜면 **선택한 모니터 전체 이미지**가 모델에 전달됩니다. Vision을 설정한 경우 문자 추출 요청도 전송됩니다. 발표와 관계없는 창을 해당 화면에 놓지 마세요.
- 앱은 정상 실행 중 화면 이미지를 메모리에 유지하며 녹음/이미지 파일을 자동 저장하지 않습니다. 별도 개발 검증 명령은 보고서와 스크린샷을 저장할 수 있습니다.
- 클라우드 측 보관·지역·접근 제어는 본인의 Azure 서비스 조건과 설정을 확인하세요.
- API 키는 EXE에 내장되지 않지만 로컬 설정은 암호화 저장소가 아닌 개인 평문 파일입니다. 설정 파일을 공유하지 말고, 유출 시 해당 Azure 키를 재발급하세요.

## 사용량이 발생하는 때

- 실행 시 설정이 있으면 Speech 사전 연결 및 작은 모델 준비 요청을 수행합니다. “번역 시작 전에는 항상 비용 0”이라고 가정하지 마세요.
- 발화 중 음성 인식/번역, 모델의 입력·출력 토큰, 첨부 이미지, 선택적 Vision 호출이 각각 사용량에 반영될 수 있습니다.
- `발화 확정 전 번역 준비`는 지연을 줄이기 위해 추가 요청을 할 수 있습니다. 비용을 줄이려면 이를 끄고, 필요할 때만 화면 분석을 켜세요.
- Speech 중지와 화면 분석 중지는 별도입니다. 사용을 끝냈으면 앱을 종료하세요.
- 월 사용 가능 시간은 모델, 발화량, 이미지 크기, 무료 한도, 구독 가격에 따라 달라집니다. 짧은 실제 시험을 한 뒤 Azure Cost Management에서 해당 리소스의 비용을 확인하세요. 비용 반영에는 지연이 있을 수 있습니다.

이 프로젝트의 CI/오프라인 빌드는 Azure 키를 요구하지 않으며 Azure 리소스를 생성하지 않습니다. Azure 리소스의 생성·결제·정리는 각 사용자가 자신의 구독에서 결정합니다.
