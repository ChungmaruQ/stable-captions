# 실행하기

전체 안내: https://github.com/ChungmaruQ/stable-captions

1. 본인 Azure Speech 및 Azure OpenAI 모델을 준비합니다. 저장소 `docs/AZURE_SETUP.md`를 참고하세요.
2. `StableCaptions.exe`(영어/한국어 선택) 또는 `StableCaptions_JP-VN.exe`(일본어+베트남어)를 실행합니다.
3. 메인 화면에 Speech 키/지역을 넣습니다. `슬라이드 화면 분석 · 맥락 번역 설정`에서 모델의 기본 엔드포인트/키/배포 이름을 넣습니다. Vision 설정은 선택입니다.
4. 설정 창을 닫고 메인 화면의 **내 Azure 설정 저장**을 누릅니다. 이 PC의 별도 파일에 저장되며 EXE에는 들어가지 않습니다.
5. 시스템에서 기본 마이크를 고르고 자막 표시 화면·위치·출력 언어를 선택합니다.
6. `번역 시작`을 누르고 **준비 완료 · 말씀하세요** 표시를 기다립니다. 사전 연결은 준비 시간을 줄이지만 네트워크·음성 인식·번역에 따른 지연을 완전히 없애지는 않습니다.
7. 슬라이드 분석이 필요하면 맥락 설정의 `화면 분석 시작`도 누릅니다. 영어/한국어 출력 앱은 설정창을 열어 두고 분석 기록·미리보기를 확인할 수 있습니다. JP/VN 앱은 설정창 최소화가 필요합니다. 선택한 화면 전체가 모델로 전달됩니다.
8. 종료할 때 화면 분석 중지 → 번역 중지 순서로 누르거나 앱을 종료합니다. 번역만 중지하면 별도로 켠 화면 분석이 계속될 수 있습니다.

## Windows 필수 구성요소

새 PC는 Microsoft의 [Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)를 설치해야 할 수 있습니다. [Speech SDK 설치 안내](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/quickstarts/setup-platform)를 따르세요. 앱 실행에 Python 설치는 필요 없지만, EXE를 직접 빌드할 때는 Python이 필요합니다. Windows 개인정보 설정에서 데스크톱 앱의 마이크 접근도 허용하세요.

## 짧은 실제 확인

- 한국어: “이 물질은 효과가 있을 수 있지만 아직 입증되지 않았습니다.”
- 영어: “The dose was five milligrams. The effect has not been confirmed.”
- 출력 언어와 부정 표현·수치가 보존되는지 확인합니다.
- “음… 이 결과를 보겠습니다.”에서 비의미적 추임새가 억제되는지 확인합니다.
- 말하기를 멈추고 남아 있는 표시 대기 자막까지 끝난 뒤 약 5초 후 마지막 자막이 지워지는지 봅니다.
- 영어/한국어 출력 앱에서 연결을 유지한 채 10초 이상 말하지 않으면 `[대기 중]`이 표시되는지, 다음 발화에 사라지는지 봅니다. 이는 자막 상태 표시이며 발화 기록에 추가되지 않습니다.
- 발표 슬라이드를 바꾸고 약 15초 내 이미지 미리보기가 갱신되는지 봅니다. 작은 포인터 움직임만으로 불필요한 갱신을 줄이도록 되어 있습니다.

비원어민 영어는 자동 언어 감지가 틀릴 수 있습니다. 행사 전에 실제 마이크와 연자의 발음으로 확인하세요. 전문 용어·부정·숫자 오인식이나 필터 누락이 절대 없다고 보장하지는 않습니다.

## 문제 해결

| 현상 | 먼저 확인할 것 |
|---|---|
| 첫 실행에서 자막 없음 | 개발자 키는 없습니다. 본인 키/지역/모델 배포를 넣고 저장했는지 |
| Speech 연결 실패 | 리소스 키와 지역의 조합, 무료 한도, 네트워크, 마이크 접근 권한 |
| 인식되는데 번역 안 됨 | 모델 엔드포인트·키·배포 이름, 맥락 번역 선택, 모델 호환성 |
| 모델 연결 오류 | 앱별 배포 이름/요청 매개변수 계약과 Chat Completions·이미지 지원 여부 ([모델 설정](AZURE_SETUP.md#모델-호환성)) |
| 429/한도 관련 오류 | 본인 구독의 Speech 한도 및 모델 TPM/RPM 쿼터 |
| 이미지 반영 안 됨 | 화면 분석을 별도로 켰는지, 캡처 화면 선택, Mac 화면 기록 권한과 분석 기록. JP/VN 앱은 설정 창 최소화 |
| Vision을 넣지 않음 | 이미지 자체는 사용 가능. 문자 힌트는 없음 |
| 설정이 저장 후 바뀜 | AZURE_* 또는 STABLE_CAPTIONS_CONFIG 환경변수 확인 |
| 중지했는데 호출 발생 | 화면 분석도 껐는지, 앱이 재시작용 사전 연결을 준비 중인지 확인. 완전 종료하면 멈춤 |
| Windows가 실행을 차단 | 서명되지 않은 자체 빌드입니다. 조직 정책을 따르고 출처·해시를 확인. 보안 도구를 끄지 마세요 |

macOS는 마이크 및 화면 기록 권한을 허용한 후 앱 재시작이 필요할 수 있습니다. 두 자막 앱을 동시에 실행하면 마이크와 화면, 비용이 중복되므로 하나씩 사용하세요.

## 영어/한국어 출력 앱의 진단 기록

맥락 설정의 **분석 기록** 탭에서 캡처 준비, OCR 완료/실패, 교정·번역 전송, 이미지 첨부 개수와 응답 시간을 확인합니다. **진단 로그 폴더 열기**로 JSONL 파일을 볼 수 있습니다.

- Windows: `%LOCALAPPDATA%/StableCaptions/Logs/EN-KO.jsonl`
- Mac: `~/Library/Logs/StableCaptions/EN-KO.jsonl`
- 파일당 512 KiB, 이전 파일 2개까지 순환 보관합니다. API 키, URL, 발화, OCR 본문, 이미지 내용은 일반 로그에 저장하지 않습니다.
- 화면 분석 시작/중지와 음성 시작/중지는 별도입니다. `[대기 중]`은 음성 연결을 끄는 기능이 아닙니다.
- Mac 캡처에는 macOS 14 이상의 ScreenCaptureKit API가 필요합니다. Windows 창 제외에는 Windows 10 2004 이상과 DWM이 필요하며 Windows 11에서 확인했습니다.
- 재빌드 후 Mac 권한이 켜져 있는데도 거부되면, 이전 동명 앱 대신 현재 빌드 파일을 권한 목록에 등록하고 재실행합니다. 권한을 우회하거나 OS 보호 기능을 끄지 않습니다.
